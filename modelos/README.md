# Modelos 

A partir da api do open router fazer a mesma pergunta para diversas LLMs gratuitas com um JSON de extração dos componentes, desse modo querendo o próximo passo ao analisar qual a melhor performance apenas com o JSON ou a Imagem e com ambos.
Depois disso verificar através do percurso cognitivo a eficacia.

O prompt do modelo foi gerado com base nesse prompt para o chatGPT5 para a primeira versão teste:
"preciso de um prompt para uma LLM que funcionará de guia para o usuário fazer uma tarefa, então ela dará a melhor opção a partir do JSON dado a ela ou a imagem em anexo"

Codigo foi aprimorado pelo Claude LLM para permitir multi-modal e logs legíveis.
