# ICLLMs 

Repositório criado para armazenar todos os códigos utilizados para a extração de componentes e testes com a LLMs 

Especificações do Sistema para retirar as prints 
- Resolução 1920 * 1080
- Para LibreOffice Windows 
- Para Americanas e Prefeitura de Limeira Garuda Linux.
- Navegador Google Chrome

Para utilização do OPENRouter para testes de LLMs 
Criar um .env 
`OPENROUTER_API_KEY = apikey`
